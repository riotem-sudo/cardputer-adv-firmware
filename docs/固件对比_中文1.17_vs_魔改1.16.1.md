## 分区表（两者完全一致）
| 分区 | 偏移 | 大小 |
|---|---|---|
| nvs | 0x9000 | 24 KB |
| factory (app) | 0x10000 | 0x4E0000（4.9 MB） |
| spiffs | 0x4F0000 | 3 MB |
| coredump | 0x7F0000 | 64 KB |

两个文件都只写到 app 区末尾（A 止于 0x4C67E0，B 止于 0x3F9BF8），**都包含 spiffs 区内容为零**。
所以刷写地址：**两者都是 0x0**。

## 实质差异（不是"新旧"那么简单）

### 1. 中文层是 A 唯一的独占优势 —— 但它占了约 800 KB
A 的 app 比 B 大 832 KB，绝大部分是 12px/16px 两级点阵字库（GB2312 全集）。
A 里能搜到真实中文串：`小时制`、`信息`、`中间人`、`投毒`、`欺骗` 等；B 一条真中文都没有。

### 2. SubGHz：A（1.17）明显更强
A 独有整套 **ProtoPirate 汽车钥匙协议**：
```
Chrysler V0 / Ford V0 V1 V2 V3 / Ford_TPMS / Kia V0 V1 V2 V3 V4 V7 / Mazda V0
RTL full 32-bit seed search / Ralink LFSR reconstruction / Decoded frames / MHz UP/DN pan
```
字符串计数：`SubGHz` A=31 / B=18，`Radio` A=24 / B=12，`Encoder` A=21 / B=13，`RAW` A=101 / B=83。
→ 刷 A 之后 SubGHz 录制/回放和车钥匙协议这块是实打实的升级。

### 3. RFID / EMV：反而是 B（1.16.1）更完整
B 独有：
```
EMVReader: Unsupported RFID module for EMV reading.
Failed to read EMV Card. / Waiting for EMV card... / EMV Read complete
VISA card detected / MasterCard / Cirrus / Electron
PAN parsed with / without workaround
```
A 的 EMV 换成了另一套实现（`EMV requires a PN532` / `Hold EMV card near NFC` / `Malformed EMV directory`），
**卡组织识别（VISA/MasterCard）和 PAN 解析相关串在 A 里不存在**。
→ 如果你要靠 PN532 读银行卡信息，1.16.1 那套更全；1.17 中文版这块被简化了。

### 4. B 有一个作者私加的定制：`ADVLED`
`ADVLED` 这个串只在 B 里出现，A 没有。结合 B 是 ADV 魔改专用编译版，这大概率是作者为 ADV 的 LED 行为加的私有改动，1.17 通用版里不存在。

### 5. 两边都能认 ADV，但 CC1101 的默认状态不同
- A：源码里明写 ADV 探到后 CC1101 **CS 默认 = -1**（注释：GPIO13 让给 GPS TX），要用得自己去 `Set Device pins` 填
- B：这是 JosephCGS 针对 CC1101+NRF24+IR 魔改硬件**编译进去**的，开机即用，但引脚值写死在代码里，改不动（除非换固件）
- 两者 CCD1101/NRF24 的实际引脚值并不一致，说明作者各自的板子接线不同

### 6. 一个可疑点：B 的"1.16.1"名不副实
B 的编译日期是 `Jul 15 2026`，而上游 1.16.1 是 2026-08-11 才发布、1.16 是 2026-07-24。
也就是说 B 很可能是一个 **1.16 开发期快照**，作者直接命名成 1.16.1 打包。
这和上一轮发现的"1.15 的 exe 内嵌镜像与仓库 bin 不一致"是同一类问题：**这个仓库的版本标注不可信，别按文件名判断新旧**。

## 结论 / 建议

| 你的目标 | 选哪个 |
|---|---|
| 要中文界面 | A（1.17-zh），但 CC1101 要手动配 CS，且失去作者的 ADV LED 定制 |
| 要 CC1101/NRF24 开箱即用 | B（1.16.1），但纯英文、EMV 以外功能比 1.17 少 |
| 想吃两边好处 | **用 A 的源码（已给你 `源码_Bruce-Cardputer-zh.zip`）把 CC1101 CS 直接编译进去** → 中文 + 1.17 新协议 + 硬件适配，一步到位 |

如果只是想快速对比体验，先刷 A（1.17-zh），进系统后 `配置 → Set Device pins` 把 CC1101 CS 改成你实际接线那位（不确定就先量板子）。刷之前务必先备份 8 MB 全片。
