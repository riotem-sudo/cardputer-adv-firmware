# Bruce 中文合并固件 · 功能使用说明（Cardputer ADV）

适用固件：`Bruce-CardputerADV-1.17-zh-CC1101-NRF24-IR_合并.bin`
平台：M5Stack Cardputer **ADV**（ESP32-S3FN8 / 8MB Flash）
依据：本固件源码里的真实菜单结构（不是通用 Bruce 文档）

---

## 〇、先看这三件事

### 1. 按键

Cardputer 是键盘机，Bruce 把键盘重映射成了导航键：

| 键 | 作用 |
|---|---|
| `;` | 向上 / 上一个 |
| `.` | 向下 / 下一个 |
| `,` | 向左 / 上一页 |
| `/` | 向右 / 下一页 |
| `Enter` | 确认 / 选中 |
| `Backspace` 或 `` ` `` | 返回 / Esc / 中断 |
| 侧边 **G0** 肩键 | 也是"确认"（等同于 Enter） |
| 字母/数字键 | 输入框中直接打字，`Fn` 组合出符号 |

长按 `;` `.` 会连续滚动；大多数长流程（发射、扫描、爆破）按 `Backspace` 立刻中断。

### 2. 硬件前提

| 功能 | 需要什么 |
|---|---|
| RF / SubGHz / 频谱 / 暴力破解 / UNILARM | **Cap-CC1101**（本固件已配好：CS=5、GDO0=15、POWER_EN=3、SW0=13；SPI 40/39/14） |
| NRF24（扫描/频谱/MouseJack/干扰） | nRF24L01+ 模块，CS=6、IO0=4（与 NFC 的 SS 复用，不能同时用） |
| IR 收发 | 默认 TX=44；Cap-IR 在 `配置 → 设置设备引脚` 里切 3/4/5/6/13/15 |
| RFID 高频 | PN532（I2C：G33/G36 可选；或 UART/BLE 版） |
| RFID 125kHz | RDM6300 类模块（默认走 UART） |
| Amiibolink / Chameleon | BLE 外设，走蓝牙连接 |
| SRIX / ST25R3916 | 需对应 SPI 板 |
| WiFi / BLE | 板载，无需外设（注意：无 PSRAM，WiFi+BLE 同时开会吃紧） |
| Ethernet | 外接 W5500（SPI） |
| LoRa | SX1276 / SX1262 模块 |
| GPS | UART GPS 模块（波特率/引脚在 GPS → Config 里设） |
| 文件 / 脚本 / 录音 / 抓包 | microSD，**FAT32** |
| BadUSB / USB 键盘 / U2F / Mass Storage | USB-C 线接到目标电脑 |

### 3. 默认引脚（本固件已写入，开箱即用）

```
CC1101:  CS=5  GDO0=15  POWER_EN=3  SW0=13  SCK=40  MISO=39  MOSI=14
NRF24:   CS=6  IO0=4    SCK=40   MISO=39   MOSI=14
NFC(SPI):SS=6  IRQ=4
IR TX:   44（可换 3/4/5/6/13/15）   RGB: 21
```

要改：`配置 → 设置设备引脚`（改了会存进 NVS，重启保留）。

## 三、RF（Sub-GHz，核心模块）

菜单：`RF`，全部依赖 Cap-CC1101。

| 子项 | 干什么 | 怎么用 |
|---|---|---|
| Scan/copy | 扫频 + 录制 + 回放 | 最常用。扫到信号后可保存 `.sub`、重放、看信号详情 |
| ProtoPirate | 车钥匙协议分析（1.17 新特性） | 针对 Chrysler/Ford/Kia/Mazda 等，能解帧/还原种子 |
| Record RAW | 裸波形录制 | 不依赖协议解码，适合未知编码 |
| Custom SubGhz | 手动构造发射 | 自定义频率/协议/码值 |
| Spectrum | 频谱图 | 扫频找信号，配合天线效果更好 |
| RSSI Spectrum | 单频 RSSI 曲线 | 判断某频点有没有活动 |
| SquareWave Spec | 方波频谱 | 观察调制形态 |
| Spectogram | 瀑布图 | 时间-频率二维，抓间歇信号 |
| Listen | 只听不发 | 长时监听，按 Backspace 退出 |
| Bruteforce | 固定码暴力枚举 | 见下 A |
| UNILARM (DIP) | UNILARM 拨码分段发射 | 见下 B |
| Jammer | 频段干扰 | 只用于自测/屏蔽，别长时间开（发热、违法风险） |
| Config | TX/RX 引脚、模块类型、频率 | 换硬件后在这里改 |

**A. Bruteforce（暴力破解）**

8 条协议：

| 协议 | 位宽 | 典型场景 |
|---|---|---|
| Came 12bit | 12 | 欧式门禁/闸机 |
| Nice 12bit | 12 | Nice 门机 |
| Ansonic 12bit | 12 | Ansonic 门机 |
| Holtek 12bit | 12 | HT12X 编码遥控 |
| Linear 10bit | 10 | 美式车库门 |
| Chamberlain 9bit | 9 | Chamberlain 车库门 |
| **Princeton 24bit（PT2262）** | 24 | 大陆最常见的 2262/2260 遥控 |
| **LinearDelta3 8bit** | 8 | Linear Delta3 系列 |

菜单项：

- `Start` 开始
- `Frequency: 433.92` 选频（315/433.92/868 等）
- `Protocol: Princeton 24bit` 选协议
- `Bits: 12/24` **关键**：决定扫多少位。全扫 24bit 是 1677 万条，要 4 天；一般先按 12bit（4096 条，约 2 分钟）试
- `Repeats: 1` 每条重复次数，遥控不响应就加到 3~5

进度条显示十六进制当前码/总量。`Backspace` 中断。

**B. UNILARM (DIP)**

25bit 固定码 = 16bit 拨码地址 + 9bit 按键指令，**不做 2^25 全扫**（要跑十天），改成 16 段 × 4096 定向发射：

- `Address: 0-FFF` 选地址段（共 16 段，一段约 5 分钟）
- `Button: Btn1/Btn2/All0/All1` 选按键位（Btn1=110000000、Btn2=001100000 是公开值）
- `Repeats: 4` 重复次数
- 默认 433.92MHz，可选 330MHz

**说明**：脉形（bit0=150/650µs、bit1=550/250µs）取自社区实测，不是官方编码器常量。门机没反应时，改源码 `ul_send_frame()` 里四个数字重编。

菜单：`NRF24`，需 nRF24L01+ 模块。

| Spectrum | 2.4G 频谱（WiFi/BLE/Zigbee 都能看到） |

## 七、IR（红外）

菜单：`IR`

| 子项 | 干什么 |
|---|---|
| TV-B-Gone | 批量发送"关机"码，走一圈把所有电视关掉 |
| Custom IR | 选择/发送红外码库（电视、空调、风扇、音响、灯带等），也可发 `.ir` 文件 |

| Config | TX/RX 引脚、TX 重复次数 |

引脚：默认 TX=44；用 Cap-IR 时在设置里切 3/4/5/6/13/15，RX 同理。`IR Read` 必须有接收头，只有发射脚学不了。

## 十七、常见问题

| 现象 | 原因/处理 |
|---|---|
| SubGHz 收不到任何信号 | `配置 → 设置设备引脚` 看 CC1101 是否 CS=5、GDO0=15；再看 Cap 是否插好（POWER_EN=3 要拉高） |
| 发射后门没反应 | 协议/位宽不匹配；先用 `Scan/copy` 录下原遥控，看解出的协议，再决定用哪条暴力破解 |
| NRF24 与 NFC 冲突 | 二者 CS 都是 6，退出一个再用另一个 |
| WiFi 功能报内存不足 | 8MB 无 PSRAM，WiFi+BLE 同开会爆；先 `Turn Off WiFi` 或重启 |
| EMV 读不到卡 | 需要 PN532 且卡是接触式/非接触 EMV；普通门禁卡不走 EMV 流程 |
| 中文显示成方框 | 该字不在 GB2312 字库里；需重跑 `tools/gen_zh_font.py` 扩字库 |
| 刷完开不了机 | 用 0x0 全量镜像重刷；仍不行加 `--erase-all` |
| WebUI 打不开 | 先 `Start WiFi AP`，手机连 `BruceNet`（密码 `brucenet`），再访问 `192.168.4.1` |

## 十八、刷机与回滚（速查）

```
# 刷入（0x0 全量，不动 spiffs）
esptool.py --chip esp32s3 -p COM5 -b 460800 write_flash \
  --flash_mode dio --flash_freq 80m --flash_size 8MB \
  0x0 "Bruce-CardputerADV-1.17-zh-CC1101-NRF24-IR_合并.bin"
```

- 备份：刷之前先 `esptool.py read_flash 0x0 0x800000 backup.bin`

## 十九、合规边界（必须说清）

- **无线电发射**：SubGHz 干扰、FM 广播、deauth 洪泛在绝大多数司法辖区属违法，只能屏蔽环境下自测；
- **门禁/车库/车辆**：只在自有或书面授权的设备上做渗透测试，破解他人门禁属刑事问题；
- **银行卡/EMV**：读他人卡片信息涉及金融隐私，属严重违法；
- **医疗/工业设备**：本固件所有无线功能都不应用于此。

工具本身中性，用在哪由你负责。
